隐私政策

应用：股息流（Dividend Flow） · 网址：dividend-flow.onrender.com
生效日期：2026 年 11 月 6 日

本政策说明「股息流」联机功能如何收集、使用与保护你的信息。本游戏为个人开发的非商业作品，仅提供在线对战与账号服务。

1. 我们收集哪些信息

  • 注册信息：用户名、邮箱地址、密码、密保问题与答案。
  • 游戏数据：联机对战产生的战绩统计（对局数、胜场、破产次数、回合数等）。
  • 技术信息：服务端日志中的 IP 地址与请求时间，仅用于安全审计与防暴力破解。

密码与密保答案均使用 bcrypt 加盐哈希后存储，服务端不保存、也无法还原明文。

2. 这些信息用来做什么

  • 创建账号、登录校验、联机对战与战绩展示；
  • 忘记密码时，通过邮箱重置链接或密保问题自助重置密码；
  • 对登录、找回密码等接口做失败次数限制，防止暴力破解和滥用。

3. 关于邮件

我们只在你主动使用「忘记密码 → 改用邮箱」时，向你的注册邮箱发送一封包含重置链接的邮件，由本应用配置的 Gmail 账号经 Gmail API 发出。重置链接一次性有效、30 分钟过期。我们不会发送营销邮件，也不会把邮箱地址用于广告或提供给他人。

4. 存储与安全

账号与战绩数据存放在 Supabase 提供的 PostgreSQL 数据库中；本地开发环境下可能使用本地 JSON 文件。全站通过 HTTPS 传输。除上述基础设施服务商（Render 应用托管、Supabase 数据库、Google Gmail API 发信）为提供服务而处理数据外，我们不会出售、出租或向任何第三方共享你的个人信息。

5. 数据保留与删除

账号数据在你使用本游戏期间保留；密码重置令牌在过期后失效并清理。你可以发送邮件至下方联系邮箱申请删除账号及其关联战绩，我们会在核实身份后处理。游戏内未提供的信息我们不会额外索取。

6. 浏览器本地存储

我们使用浏览器 localStorage 保存登录令牌与本地游戏设置，用于保持登录状态。这些数据只留在你的设备上，不用于跨站追踪或广告投放。

7. 儿童隐私

本游戏不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

8. 政策变更

如本政策有更新，将直接在本页面公布并修改顶部生效日期，不会另行发送通知邮件。

9. 联系我们

如对隐私或账号数据有疑问、需要删除账号，请发送邮件至：tomkim413@gmail.com。
